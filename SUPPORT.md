# Support

Doq is maintained by volunteers; support is best-effort and happens on GitHub. There is no chat server, mailing list or discussion forum.

| You have…                | Do this                                                                                                                                                                                                                               |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A usage question         | Read the [package README](packages/doq/README.md) and [CHANGELOG](packages/doq/CHANGELOG.md), then open an issue with the bug report form and start the title with "Question:" if the docs do not answer it. Include a minimal setup. |
| A bug                    | [Open a bug report](https://github.com/Andersseen/doqs/issues/new?template=bug_report.yml) with versions, a reproduction, and expected vs. actual behavior.                                                                           |
| A feature idea           | [Open a feature request](https://github.com/Andersseen/doqs/issues/new?template=feature_request.yml) describing the consumer problem first.                                                                                           |
| A documentation problem  | Open an issue (bug report is fine) or a pull request that fixes the page. Public API changes must update the README and CHANGELOG.                                                                                                    |
| A security vulnerability | Do **not** open a public issue. Follow [SECURITY.md](SECURITY.md).                                                                                                                                                                    |
| A conduct concern        | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).                                                                                                                                                                                      |

Before filing, search existing issues. To contribute a fix yourself, see [CONTRIBUTING.md](CONTRIBUTING.md).
