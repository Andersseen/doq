## Limitations

- No unit-test framework was added; coverage is the browser harness plus packed-artifact checks.
- Slots take no inputs or per-document data.
- Angular 22 remains unvalidated (peer range only).
- Setting `documentationLabel` also changes the breadcrumb root from `Docs` to that label.
- The index now sets the page title (previously untouched).
