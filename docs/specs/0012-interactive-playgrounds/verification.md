## Remaining limitations

- Screen-reader output was not tested (axe, keyboard journeys and the accessible-name contract were). WCAG conformance is not claimed.
- Overlays a previewed component appends to `<body>` render below the Expand dialog's top layer (documented, not fixed).
- Controls are not inferred from `doq-api` metadata. Object-graph inputs need a wrapper component.
- Angular Movement's `MoveEnterDirective` plays once in `ngOnInit` and has no outputs; the proof's wrapper recreates the target element per input combination and defines its own `played` output. The generic contract needed no change.
- The 0.9.0 package is not published and the site is not deployed from this branch. After the merge the release workflow must run for 0.9.0 and, because 0.8.0 never reached npm, the maintainer should decide whether 0.8.0 is published retroactively or skipped (the plan job publishes the version of the commit it runs on). Cloudflare Pages deployment runs from `deploy-site.yml` after CI on `main`.
- Showcase A's embedded initial JavaScript is 210,247 B gzip against a 212,400 B budget (about 1% headroom); the budget was not raised.
