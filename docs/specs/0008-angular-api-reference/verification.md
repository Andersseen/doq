## Remaining limitations

- **READY with these caveats, none hidden:** `0.5.0` is prepared, not published; publication happens through the existing release workflow after merge and green CI, and is reported separately. The missing `v0.4.0` GitHub Release is not created automatically; that is a maintainer decision (see operations notes).
- Links inside Markdown are ordinary anchors (Analog does not intercept them): following a reference link is a normal navigation to a prerendered page, not a client-side route change.
- Union and generic types are code spans, so names inside them are listed under "Related types" rather than linked in place.
- Computed decorator metadata, inline-arrow input transforms ("(inline function)") and very long constant types are reported or shortened, never guessed.
- The Angular Movement proof ran against a disposable checkout only; Angular Movement is not migrated and its repository was not modified. The Analog heading-id race makes that proof rebuild several times.
- TypeScript is covered at 5.9 and 6.0 only; Angular types are required for Angular-specific extraction (otherwise explicit type arguments plus a warning).
- E2E-062 and the heading-id race are the known sources of intermittent timing failures; neither is caused by this change.
