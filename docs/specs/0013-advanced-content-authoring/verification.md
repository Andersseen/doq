## Remaining limitations

- Directives are line-level and stay literal inside block quotes, lists and tables; diagnostics inside a fragment name the fragment, not the including page.
- Windows paths and `fs.watch` behaviour on Linux were not exercised; `doq content watch` was exercised by its unit-tested Vite counterpart and a manual dev-server run, not by an automated test of the CLI watcher.
- Source links were exercised with a reserved `example.invalid` host in the showcases and `github.com/Andersseen/doqs` at the branch name `main` in the official documentation (lines drift as `main` moves; a tag is the right choice for archives).
- Pagefind indexes code text of source blocks like any code block (existing policy); `View source` links are indexed as prose.
- The Angular Movement proof needs one marker comment added in the disposable checkout; it never modifies the real repository.
- Screen-reader output was not tested; axe passes in light and dark themes on the embedded guide.
- Real consumer adoption of 0.10 beyond the disposable proof is still outstanding; see the 1.0 readiness document.
