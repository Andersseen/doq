## A system, not a skin

Vanta gives product teams a flexible set of interface foundations. Keep the tokens, navigation, and product identity your application already owns.

> [!TIP] The docs shell inherits semantic theme roles from the host application. Switch themes from the site header to see the same docs adapt.
