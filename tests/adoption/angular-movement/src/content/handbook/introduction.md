## Why Angular Movement?

Angular Movement packages motion patterns as declarative directives for standalone components.

## Installation

Pick a package manager and copy the command:

::demo[install-command]

After the install command, add `provideMovement()` to your application providers.

## Try your first animation

::demo[enter-animation]

The directive above is a real `moveEnter` host component owned by the application, not by the documentation framework.
